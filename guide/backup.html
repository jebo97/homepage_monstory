데이터 백업하고 복원하기

몬스토리의 기록은 계정에 저장되어 여러 기기에서 이어지지만, 만일을 대비해 파일로도 받아 둘 수 있어요. 백업은 거래 내역(엑셀)과 설정(JSON) 두 가지로 나뉩니다.

1. 거래 내역 백업 — 엑셀

  1. 더보기 › 데이터 관리로 갑니다.
  2. 데이터 내보내기에서 엑셀로 내려받기를 누릅니다.

수입·지출·저축·보험·대출·카드대금이 유형별 시트로 나뉜 엑셀 파일 하나가 받아지고, 월별 요약 시트도 함께 들어 있어요. 이 파일은 그대로 다시 올리면 복원됩니다.

바로 아래 CSV로 내려받기는 모든 유형을 한 장에 모은 파일이에요. 다른 앱으로 옮기거나 스프레드시트로 볼 때 편하지만, 시트를 나눌 수 없어 복원용으로는 엑셀을 받아 두세요.

2. 설정 백업 — JSON

같은 화면 아래 설정 백업 · 복원에서 설정 백업(JSON)을 누르면 설정 파일이 따로 받아집니다.

직접 만든 카테고리, 카드·금융상품, 예산, 연례 이벤트, 한 달 기준 같은 설정이 담겨요. 거래 내역은 담기지 않으니 엑셀 백업과 함께 받아 두세요.

3. 복원하기

설정 복원

설정 백업 · 복원의 설정 복원을 눌러 JSON 파일을 고릅니다. 지금 설정을 파일 내용으로 덮어쓴다는 확인이 뜨고, 확인하면 바로 적용돼요. 거래 내역은 영향을 받지 않습니다.

거래 내역 복원

데이터 가져오기에 백업 엑셀을 그대로 올리면 시트별로 나눠서 한 번에 들어갑니다. 이미 기록이 있는 달이 있으면 기존 내역에 더하기 · 그 달을 파일로 교체 · 그 달은 건너뛰기 중에서 고르는 창이 떠요.

같은 백업 파일을 기록이 있는 달에 더하기로 올리면 같은 거래가 두 번 들어갈 수 있어요. 백업 시점으로 되돌리려는 거라면 교체를 고르세요. 교체로 밀려난 내역은 휴지통에서 되돌릴 수 있습니다.

설정을 먼저 복원한 뒤 거래 내역을 올리면, 직접 만든 분류가 처음부터 제자리에 보여서 깔끔합니다.

4. 백업을 잊지 않도록

마지막 전체 백업 후 90일이 지나면 홈 화면 인사이트에서 "만일을 대비해 가끔 전체 백업을 해두면 좋아요"라고 알려 드려요. 분기마다 한 번, 그리고 분류를 크게 바꾸거나 내역을 많이 지우기 전에 한 번씩 받아 두시길 권합니다.

휴지통과는 어떻게 다른가요

더보기 › 휴지통은 실수로 지운 내역을 90일 동안 보관했다가 되돌리는 곳이에요. 내역 몇 건을 살리는 데는 편하지만, 기록 전체를 따로 보관하는 백업을 대신하지는 않습니다.

몬스토리는 기본 가계부 기능을 무료로 제공해요. 가입 전에 샘플 데이터로 먼저 둘러보셔도 됩니다.
